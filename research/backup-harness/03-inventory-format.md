# Формат файла кандидата — обязателен к соблюдению

Читать ДО начала работы. N инвентарей в N разных формах невозможно свести.

## Правила

1. Один исполнитель — один файл. Чужие файлы не трогать.
2. Лимит 120 строк на файл. Не влезло — режь второстепенное, а не формат.
3. НЕ пересказывай содержимое файла в ответе в чат. Файл уже содержит всё;
   в чат верни 5-10 строк: что покрыл, главный вывод, где не уверен.
4. Каждый факт помечай ЗАМЕРЕНО (свой живой прогон, с командой и выводом) или
   ПО ДОКАМ (со ссылкой). Смешивать запрещено — это разные степени доверия.
5. Не знаешь — пиши "не проверено" и почему. Правдоподобная догадка хуже пробела.
6. Термины строго по `01-legend.md`. Своих определений не вводить.
