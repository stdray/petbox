`deepseek-chat` (`apply_patch_tool_type:"freeform"`; помимо полей из `42-...md` пришлось

## Применяются ли патчи

**patch-1**: одна прочитка (`cat -n`), один вызов `apply_patch` с корректным freeform-diff
(`*** Begin Patch / *** Update File: inventory.py / @@ ... *** End Patch`) — принят с первого
раза, `status:"completed"`, без ошибки формата. Затем сразу `DONE`. 3 хода.

**patch-2**: прочитка → `apply_patch` (тот же корректный формат, тоже с первого раза) →
ДОПОЛНИТЕЛЬНЫЙ `exec_command` (`cat inventory.py && grep -n "calc_total_price\|stationery\|
stock < 10\|stock <= 5" inventory.py`) — самопроверка результата патча, которую системный
промпт Codex прямо запрещает («Do not waste tokens by re-reading files after calling
`apply_patch`… The tool call will fail if it didn't work.», см. `35-bench-overhead.md` A3) —
DeepSeek это правило проигнорировал и добрал 4-й ход. Затем `DONE`.

**Итог: 0 из 2 вызовов `apply_patch` отклонено, 0 повторных попыток, 0 текстов ошибок формата
за оба прогона.** DeepSeek-chat, не обучавшийся на этом freeform-формате, воспроизвёл его
синтаксис правильно с первого раза оба раза, включая корректные контекстные `@@`-якоря на
несмежные хунки в одном файле.

## Ходов и токенов — с патчем против без

- **Ходы**: control 3, 4 (среднее 3.5); patch 3, 4 (среднее 3.5) — **одинаково**, экономии
  ходов замер не увидел (лишний ход patch-2 — не сбой патча, а необязательная самопроверка).
- **Токены**: control 28 489, 39 126 (среднее ≈33 808); patch 20 011, 27 129 (среднее
  ≈23 570) — **patch дешевле на ≈30 %** в этой паре прогонов. Правдоподобная причина: тело
  freeform-патча (только 4 хунка контекста) короче, чем что бы ни писал `exec_command` для
  тех же трёх правок (полный heredoc/sed на весь файл или многострочный python) — но сама
  команда `exec_command`-варианта не сохранена текстом (JSONL-события `file_change` не несут
  исходной команды), только байтовый результат; гипотеза о причине экономии не подтверждена
  посимвольно, только по итоговым `usage`.

## Вердикт

**Включать `apply_patch` под DeepSeek стоит** — на этих 2+2 прогонах патчи применяются с
первого раза (0 отказов), результат идентичен по корректности контролю, и стоит заметно
дешевле по токенам; ходов не больше. Ключевая оговорка из `42-...md` («включение не
гарантирует, что модель следует формату») на этой задаче не подтвердилась — но:

> [!WARNING]
> **2+2 прогона — наблюдение, не статистика.** Один тип задачи (текстовые правки в одном
> файле, 3 несмежных хунка, 40-60 строк). Не проверено: конфликтующие/неоднозначные хунки,
> патч на несколько файлов, патч поверх файла с непохожим на ожидаемое состоянием (частый
> триггер реальных отказов apply_patch), более длинная сессия, где модель могла бы накопить
> ошибку формата. При таком объёме один неудачный прогон сдвинул бы вердикт с «стоит» на
> «зависит от того-то» — это тонкий результат, не закон.
