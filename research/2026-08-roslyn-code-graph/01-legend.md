# Легенда терминов (читать ДО написания находок)

Одно слово в двух смыслах отравляет весь остаток. Ниже — фиксированные значения.

## Источники рёбер (главная ось всего исследования)

| Термин | Значение | Что видит | Чего НЕ видит |
|---|---|---|---|
| **IL** | скомпилированные сборки `bin/**` (NDepend, `System.Reflection.Metadata`) | то, что компилятор записал ребром | `const` (инлайнится), член enum в `switch` (→ сравнение с int), строки |
| **Синтаксис** | Roslyn `SyntaxTree` без семантики | лексемы, формы объявлений | разрешение перегрузок, куда именно указывает имя |
| **Семантика** | Roslyn `SemanticModel` / `ISymbol` / `FindReferencesAsync` | использование символа по ИСХОДНИКУ, включая `const` и члены enum | строки, рефлексию, DI |
| **Строки** | текстовый поиск по литералам, `.cshtml`, `.ts` | claim'ы, роуты, имена партиалов | смысл — совпадение имени ≠ ребро |
| **Рантайм-дамп** | пробег по `IServiceCollection` / `EndpointDataSource` живого приложения | реальные регистрации DI и маршруты | то, что регистрируется по условию, не выполнившемуся в дампе |

**Правило:** любая находка обязана называть источник. «Roslyn» — не источник; источник — «семантика» или «синтаксис».

## Прочее

- **Модель** — построенное представление кода (у NDepend строится из IL; у нашего прототипа — из исходников).
- **Индекс** — модель, СОХРАНЁННАЯ в хранилище и переживающая процесс. Живой `Workspace` в памяти — НЕ индекс.
- **Граф** — проекция модели в узлы/рёбра. Не источник данных (см. wiki «Индексы кода для агентов»).
- **Провенанс ответа** — метаданные результата: по каким источникам искали, что заведомо не проверялось.
- **Признак полноты** — машиночитаемый флаг «это исчерпывающий ответ» vs «это то, что я умею видеть».
- **Честный ноль** — ноль от источника, который ТОЧНО выражает искомое ребром. Всё остальное — «не искал».
- **Спрос** — список из 8 форм вопросов, реально заданных агентами за 12 задач (`02-snapshot.md`). Единственное ТЗ.

## Запрещённые формулировки

- «Roslyn это видит» без указания семантика/синтаксис — двусмысленно.
- «0 использований» без провенанса — это и есть дефект, который чиним.
- «индексация» про загрузку решения в память — путает развилку живой Workspace vs хранилище.
