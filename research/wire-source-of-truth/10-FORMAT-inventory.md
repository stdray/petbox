# Формат, обязательный для каждого файла `1x-inventory-*.md`

Читать ДО написания своего файла. N инвентаризаций в N форматах невозможно свести.

## Правила

1. **Лимит: 120 строк.** Превышение — признак, что в файл попал пересказ вместо вывода.
2. **Каждый факт о коде несёт ссылку** `путь:строка`. Факт без ссылки помечается как
   ПРЕДПОЛОЖЕНИЕ явным словом.
3. **Не пересказывать содержимое файла в чат-ответе.** В ответ оркестратору — 5-10 строк:
   что сделано, где файл, что удивило, с чем не согласен.
4. **Термины — строго из `01-legend.md`.** Нужен новый термин — добавь его в легенду отдельной
   строкой и скажи об этом в ответе.
5. **Противоречие с другим файлом или с отчётом резерва не сглаживать**, а записать в свой
   раздел «Спорное» с формулировкой «X утверждает A, я нахожу B, потому что …».

## Обязательная структура

```
# <название области>

Дата: 2026-08-30. Автор: <роль> (<модель>). Область: <одна строка>.

## Ответ одной строкой
<главный вывод; если вывода нет — так и написать>

## Факты
<нумерованный список, каждый со ссылкой путь:строка>

## Что из этого следует для гипотезы «источник истины — файлы»
<3-7 строк>

## Спорное
<противоречия; пусто — написать «нет»>

## Чего я не проверил
<честный список пробелов; пусто — написать «нет»>
```

## Тон

Пишем для человека, который вернётся сюда через неделю и не помнит контекста. Никакой
бодрости и никаких «важно отметить». Утверждение — ссылка — следствие.
