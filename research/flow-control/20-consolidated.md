## Установленная причина неверной маршрутизации

59 наблюдений сидят в `work`/Pending, то есть в полосе обязательств. Причина названа
в самой памяти проекта (`m-6143d66c6db0…`):

> «Intake — только для стороннего triage; владелец-разработчик заводит chore/bug/идею
> сразу по месту, без интейк-шлюза».

Правило разумно для владельца и **катастрофично для агента**: агент, следуя ему, кладёт
находку сразу в `work`, минуя всякий шлюз. Это не расхлябанность агентов — это
**документированное правило, порождающее ровно тот дефект, который мы разбираем**.
Правило написано для человека, а исполняется машиной, которой оно даёт полосу обязательств
как полосу по умолчанию.

## Дефекты легенды, найденные тремя агентами независимо

Все три инвентаря упёрлись в один и тот же класс проблемы — в легенде не хватает случаев.
**Инвентари сделаны по легенде БЕЗ этих поправок**, это надо учитывать при чтении.

1. **Предложение / фиче-гэп** (`intake`-агент). `memory-entry-permalink`,
   `markdown-render-memory-sessions`, `ui-show-updated-at` — не находка о состоянии системы
   и не обязательство. Агент отнёс к наблюдениям по тесту («молча закрыть → гэп останется
   гэпом»). **Разрешение: верно.** Предложение — наблюдение до тех пор, пока владелец на
   него не поставил. Легенду дописать.
2. **Умбрелла без собственных commits** (`work`-active-агент). `resharper-clt-in-pipeline`,
   `newcomer-equivalent-experience`, `roslyn-code-graph-research` сами коммитов не несут,
   работа идёт в детях. Агент присвоил обязательство по работе в детях.
   **Разрешение: верно.** Класс умбреллы = максимум по детям.
3. **Накопитель — контейнер, а не класс** (`work`-pending-агент). Отнёс к «смешанному»,
   чтобы не заводить четвёртую строку и не исказить сумму. **Разрешение: накопитель — это
   ТАРА, ортогональная классу.** И тут же вскрылось важное различие:
   - `acc-memory-secrets` заведён **по прямой цитате владельца** с решённым порядком
     («сначала память, потом секреты») — сам факт заведения есть обязательство;
   - `acc-memory-analysis-tails-0827` заведён **агентом** «чтобы не потерялось при смене
     сессии», owner-цитаты нет — целиком контейнер наблюдений.

   Внешне это две одинаковые карточки. По классу — разные объекты.
