# Формат фактовых файлов (10-, 11-, 12-)

- Язык: русский, термины/идентификаторы как есть.
- Каждый факт — со ссылкой на источник: `path:line`, id узла/сессии/памяти, URL. Без источника — помечать «(вывод)».
- Разделы: `## Факты` (нумерованные F1, F2…), `## Пробелы/противоречия`, `## Что это значит для вопросов владельца` (кратко, по вопросам Q1–Q7 ниже).
- Лимит: 250 строк. Код не цитировать крупнее 10 строк.
- В чат-ответе содержимое файла НЕ повторять — только 5–10 строк итогов.

Вопросы владельца:
- Q1 роутер как конечный автомат
- Q2 codex: разные провайдеры для субагентов
- Q3 бесплатные модели + автопереключение при отвале
- Q4 конфигурация моделей с API-ключами в роутере
- Q5 пользовательский шлюз в PetBox для своих машин
- Q6 автономный локальный шлюз (dotnet tool / служба)
- Q7 переписывание заголовков на шлюзе
