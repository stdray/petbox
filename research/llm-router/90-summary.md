## Ответ на вопрос «модуль требует убийства?» — нет

- **Внутренний embed/rerank-роутер доказал свою работу на проде**: за 7 дней 805 переездов embed/rerank
  дом→openrouter, из них 79% — через `EndpointBreaker` (домашний узел уже помечен open, запрос сразу идёт
  в облако, без ожидания connect-timeout) (80 §3). У бесплатного Bifrost автоматического отключения
  сбойного эндпоинта нет — это Enterprise (80 §2); agentgateway отключает только для следующего запроса,
  без retry внутри запроса (80 §1). Замена ухудшила бы ровно то, что реально работает.
- **`EmbedSpaceId` и rerank-affinity внешне не выражаются** (63): за «виртуальной моделью» шлюза
  гарантия одного пространства превращается в дисциплину конфига (80 §4).
- **K2 не убийство**: удаляет ~450 проверенных строк fallback/breaker, оставляет ~1500 строк реестра/UI/MCP (80 §3).
- **Свой .NET-шлюз (30-proposal) не оправдан**: codex-кейс закрывается готовым локальным шлюзом.

## Что меняет 66 (внешние потребители) — главная открытая развилка

chat-agent просит tools/tool_choice/tool_calls и стриминг, archive — vision content-parts. Сейчас chat-путь
модуля отдаёт `string` и всё это теряет, поэтому chat-agent ходит к провайдерам мимо роутера и теряет fallback
и учёт. Chat на сервере почти не падает (2/815) — т.е. потребителям нужен не fallback, а **полнота протокола**.
Резерв (80) предлагал «серверный шлюз только по измеренному триггеру» и не видел 66 — триггер (реальный спрос
на tools/stream) уже есть.

## Развилки для владельца

1. **Chat для внешних проектов** — (а) достроить сквозной chat в модуле: `tools`/`tool_choice`/`tool_calls`,
   content-parts, SSE; capability-флаг маршрута «умеет tools/vision». Цена — дни; риск — вечно догонять
   протокол OpenAI. (б) Отдельный серверный шлюз только для chat внешних проектов (agentgateway stable /
   CLIProxyAPI), embed/rerank остаются в модуле. Цена — второй сервис на VPS, ключи в двух местах, свой учёт
   usage у шлюза. Не решить — chat-agent и archive продолжают ходить напрямую, без fallback и учёта.
   Мнение оркестратора: (а), если объём — pass-through JSON без трансляции (роутер передаёт тело как есть, трогает
   только model/ключ): это ближе к твоему «почти HTTP proxy» и не требует понимать tools.
2. **Автомат во внутреннем роутере** — enum исходов + cooldown-таблица + Retry-After + QuotaExhausted + usage
   в лог. Цена 2–3 дня (40 §5). Не делать — 429 без Retry-After и «бесплатное кончилось» продолжают
   обрабатываться как обычный сбой.
3. **Локальный шлюз** — CLIProxyAPI или agentgateway (таблица выше). Цена — часы на конфиг + служба.
4. **Мультимодальный embed (archive A2)** — отдельный трек внутреннего роутера; провайдеры не оценивались.
