## Вводные владельца
- Роутер как конечный автомат (прошлые размышления — добрать).
- codex не умеет разные провайдеры для субагентов → роутер/шлюз должен решать.
- Бесплатные модели «пока дают» с автопереключением при отвале.
- Конфигурация моделей по API-ключам в роутере (подписки — ВНЕ схемы).
- Пользовательский шлюз в PetBox: мои машины подключаются к нему, он маршрутизирует.
- Тот же шлюз локально, полностью автономно, без PetBox (dotnet tool / служба).
- Переписывание заголовков на уровне шлюза.
- Уровень работы — чуть ли не HTTP proxy; но протоколы встречаются все (см. opencode-go).
- Сравнение с аналогами: наш автомат против их конфигов, затраты, легковесность (trimming/AOT).
